# 외부 작업 입력 규약

CDW는 작업에 등록한 프로그램을 별도 프로세스로 실행합니다. 데이터 입력은 `없음`, `CDW JSON 파일`, `CSV 파일` 중에서 선택합니다. 모든 방식에서 종료 코드 `0`은 성공이며, 다른 종료 코드는 실패입니다. 표준 출력과 표준 오류는 실행 로그로 수집하며, 등록한 시간과 출력 크기 제한을 적용합니다.

입력이 없으면 테이블 없이 프로그램만 실행합니다. 파일 입력을 선택하면 CDW가 전체 조회 결과의 스냅샷을 임시 파일로 만들고, 명령어의 `{input}`을 그 파일의 절대 경로로 치환합니다. 직접 실행에서는 파일 경로 전체를 한 인자로 전달합니다. 셸 스크립트에서는 `{input}`을 따옴표 없이 입력합니다. CDW가 경로에 맞는 셸 인용을 적용합니다.

입력 파일은 프로세스가 끝날 때까지 유지되며, 성공·실패·시간 초과·취소 후 삭제됩니다. 프로그램은 종료 전에 파일을 모두 읽어야 합니다. 독립적으로 남는 자식 프로세스가 나중에 읽어야 한다면 프로그램이 자체 경로에 복사해야 합니다.

## CDW JSON 형식 버전 1

파일은 BOM 없는 UTF-8 JSON 객체입니다. 수신 프로그램은 `protocol`과 `version`을 확인한 뒤 처리해야 합니다.

```json
{
  "protocol": "cdw.table",
  "version": 1,
  "run_id": "cc6f0cd0-cc39-449c-b6ae-f560ab0965e2",
  "table_name": "daily_usage",
  "collected_at": "2026-11-17T09:30:00+09:00",
  "columns": ["host", "amount", "day", "payload", "note"],
  "types": ["string", "decimal", "date", "binary", "string"],
  "rows": [
    ["host-a", "12345678901234567890.0001", "2026-11-17", {"$binary": "AP8="}, null]
  ]
}
```

`columns`와 `types`의 순서는 각 행의 값 순서와 같습니다. 조회한 컬럼명이 유지되며, 원본 DB 구현체의 자료형 이름은 아래의 안정적인 형식 이름으로 변환합니다. 빈 결과도 컬럼과 자료형을 포함하고 `rows`는 빈 배열입니다.

| 형식 이름 | JSON 값과 해석 |
| --- | --- |
| `integer` | JSON 정수. 수신 언어에서 큰 정수를 정확하게 읽어야 합니다. JavaScript의 `Number`만 사용하면 큰 정수의 정밀도가 손실될 수 있습니다. |
| `decimal` | 정확한 십진 문자열. 자릿수와 소수점 이하 값이 유지됩니다. |
| `float`, `number` | JSON 수. 유한하지 않은 값은 문자열 `NaN`, `Infinity`, `-Infinity`입니다. |
| `boolean` | JSON `true` 또는 `false`. |
| `string` | 문자열. |
| `date` | `YYYY-MM-DD` 문자열. |
| `datetime`, `time` | ISO 8601 문자열. 원본 값에 시간대가 있으면 UTC 오프셋을 포함하고, 없으면 시간대를 임의로 추가하지 않습니다. |
| `binary` | `{"$binary": "..."}` 객체. 값은 표준 Base64 문자열입니다. |
| `duration` | 원본 시간 간격의 문자열 표현. |
| `json` | 중첩 배열·객체·값. 중첩된 십진수, 시각, 바이너리에도 같은 값 변환을 적용합니다. DB의 JSON 문자열 값은 문자열로 보존됩니다. |

모든 형식에서 SQL `NULL`은 JSON `null`입니다. `run_id`는 실행 식별자이고, `collected_at`은 시간대가 포함된 스냅샷 시각입니다. 수집에 연결된 작업은 수집 대상 테이블 이름을 `table_name`으로 전달합니다. 특정 테이블을 대표하지 않는 독립 SQL 결과에서는 빈 문자열일 수 있습니다.

## CSV 입력

CSV는 BOM 없는 UTF-8이며 첫 행은 컬럼명입니다. 구분자는 작업 설정값을 사용하고, 줄바꿈은 LF입니다. 구분자·따옴표·줄바꿈을 포함하는 필드는 표준 CSV 인용 규칙을 적용합니다.

SQL `NULL`과 빈 문자열은 모두 빈 필드이므로 CSV로는 둘을 구분할 수 없습니다. 십진수와 날짜는 위 문자열 표현을 사용하고, 바이너리와 중첩 값은 JSON 표현으로 기록합니다. 자료형·실행 ID·테이블 이름·수집 시각 메타데이터가 필요하면 CDW JSON을 사용합니다.

## 실행 환경

등록 시 저장한 환경변수 전체를 프로세스에 적용합니다. 이후 서버 환경이 바뀌더라도 저장된 값에 자동으로 덧붙이지 않습니다. 작업 편집기의 환경변수 탭에서 현재 환경을 다시 불러오거나 값을 추가·수정·삭제할 수 있습니다.

현재 셸 실행은 Bash의 `-o pipefail -c` 방식입니다. 파이프라인 중간 명령이 실패하면 전체 작업도 실패로 처리할 수 있습니다. 작업 자체에서 비동기 실행을 시작하고 곧바로 종료하면 CDW는 최초 프로세스의 종료만 작업 완료로 판단하므로, 완료를 추적할 작업은 전경에서 실행해야 합니다.
